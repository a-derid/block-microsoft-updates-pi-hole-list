# Title: a-derid/block-microsoft-updates-pi-hole-list
#
# Blocks Windows Update (including drivers), the Microsoft Store,
# and Start menu / lock screen suggestions and ads.
#
# Still works: Windows activation, Microsoft Defender definitions,
# root certificate updates, Edge and WebView2 updates, Bing, Office.
#
# Not blocked by this list, but needed to keep Edge, WebView2 and
# HTTPS certificates working:
#   ctldl.windowsupdate.com       (root certificate updates)
#   msedge.api.cdp.microsoft.com  (Edge / WebView2 updates)
#
# Side effects: Microsoft Store installs and app updates will fail,
# including updates for built-in apps (Notepad, Terminal, etc.).
#
# Hosts files cannot block subdomains. Windows Update also uses
# numbered servers (e.g. 7.tlu.dl.delivery.mp.microsoft.com).
# Pi-hole users should also add this as a Regex deny rule
# for full coverage:
#
#   (^|\.)((windows)?update\.microsoft\.com|windowsupdate\.com|(delivery|dsp)\.mp\.microsoft\.com|emdl\.ws\.microsoft\.com)$
#
# and add ctldl.windowsupdate.com as an Exact allow rule.
#
# To install updates, disable this list temporarily, then
# run Windows Update.
#
# Date: 17 November 2026
# Number of unique domains: 23
#
# Project homepage:
# https://github.com/a-derid/block-microsoft-updates-pi-hole-list/
#
# Fetch the latest version of this file:
# https://raw.githubusercontent.com/a-derid/block-microsoft-updates-pi-hole-list/refs/heads/main/hosts.txt
#
